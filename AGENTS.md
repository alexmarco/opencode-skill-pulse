## Agent skills

### Issue tracker

Issues viven en GitHub Issues, gestionados con la CLI `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Los cinco roles canónicos usan sus nombres como label: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + ADRs en `docs/adr/` en la raíz. See `docs/agents/domain.md`.
